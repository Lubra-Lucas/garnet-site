# Dados e imagens simulados no protótipo

Tudo abaixo aparece no site com a etiqueta rosa **"simulado"** (botão "Protótipo" ligado).
Substitua pelos dados reais e remova a classe `sim` e a etiqueta `simtag` do elemento.

| Onde | O que está simulado | O que precisamos da Garnet |
|---|---|---|
| Números | **500 mil** unidades por mês | Capacidade produtiva mensal real |
| Números | **3.200 m²** de área fabril | Área real da fábrica |
| Números | **+150** marcas atendidas | Quantidade real de marcas/clientes |
| Números | **BPF · ANVISA · AFE ativa** | Confirmar AFE, BPF e outras certificações (vegano, cruelty-free etc.) |
| O que fabricamos | Imagens de **Perfumaria, Skincare e Cabelos** (ilustrações em CSS) | Fotos reais dessas categorias |
| Linha de produção · agora | Tabela inteira (lotes, produtos, etapas, unidades) | Decidir se vira dado real (ex.: planilha atualizada pela equipe) ou se sai do site |
| Depoimentos | 3 depoimentos (vieram do site antigo e não são clientes reais) | Depoimentos reais com autorização |
| Estojo 3D | Animação do estojo gerada por código (`tools/render-sequence`) | Render profissional ou foto/vídeo do produto real |
